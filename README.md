# Jeu de Memory

Jeu de memory en JavaScript pur : retrouvez les paires d'images cachées parmi un plateau de cartes mélangées.

🔗 [Jouer en ligne]()

## Technologies

- HTML5
- CSS3
- JavaScript

## Fonctionnalités

- Génération aléatoire des images via l'API [Picsum Photos](https://picsum.photos/)
- Mélange des cartes avec l'algorithme de Fisher-Yates
- Rendu dynamique du plateau (création des cartes en JavaScript)
- Gestion des clics avec vérification des paires
- Chronomètre et compteur de coups
- Détection de la victoire
- Bouton pour recommencer une partie
- Accessibilité : navigation clavier (`tabindex`, `role="button"`) et `aria-live` pour annoncer les résultats
